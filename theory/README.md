# Lunar Flower — Theory index

## AI seed: expert-system contract

The **Lunar Flower AI Seed** is published in the central Ethical & Intellectual Theory repository:

[Read: Lunar Flower AI Seed — Expert-System Contract](https://github.com/alia-june/ethical-and-intellectual-theory/blob/main/blue-prints/LUNAR_FLOWER_AI_SEED_EXPERT_SYSTEM_CONTRACT.md)

**Core statement:** place AI under an expert-system contract in an orchestration role; prefer rule-governed procedures; make generative synthetic decision-making a last resort; build the tools and governing structure from the ground up.

**Standing gates (canonical proposal):** [Production Lock, Reiteration, Hand-off, Informed Operator Validation, Consequence-Scaled Challenge–Response, and Prompt Restatement](https://github.com/alia-june/ethical-and-intellectual-theory/blob/main/blue-prints/LUNAR_FLOWER_AI_SEED_EXPERT_SYSTEM_CONTRACT.md#standing-expert-system-gates--generic-proposed-contracts). These six are proposed controls, **not a fixed execution sequence**. Gate 6 is numbered sixth to preserve existing identifiers but occurs at interpretation: the machine briefly restates the request as understood without treating its paraphrase as Operator agreement or permission. Gate 2 concerns candidate reiteration; Gate 4 concerns informed validation; Gate 5 provides optional consequence-scaled scrutiny. No documentation activates an operating control.

**Separate research README:** [Gate Framework — Gate 0 v0.4, G0-MOD v0.2 opt-in axioms, and Gate 6](https://github.com/alia-june/ethical-and-intellectual-theory/blob/main/blue-prints/gates/README.md). Promotion into a theoretical catalog is not project adoption, verification, or production authorization.

**Status:** theoretical proposal, not an activated AI control system and not a capability claim about Twin Lanterns or ReShade shader builds.
