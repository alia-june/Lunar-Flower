# Lunar Flower — Theory

The **Lunar Flower AI Seed** is a separate, proposed expert-system architecture. It assigns the AI a contract-bound orchestration role, prefers rule-governed and deterministic processes where appropriate, and treats generative decisions as separately reviewed last-resort candidates.

## Distinguishing the gates

The original five standing gates retain their identifiers. **Gate Six — Prompt Restatement** is now the **sixth required clearance** in the selected seven-gate sequence, following Gate Five: the machine restates the original request consistently with the exact authorized candidate, without turning the restatement into Operator agreement, consent, or authorization. **Gate Seven — Alpha-Lock** is the **second and final production gate** and may clear only if Gates One–Six have already cleared **in order**, for the same candidate and effects.

Gate Two concerns *reiteration of a candidate*, Gate Four concerns *informed Operator validation*, and Gate Five concerns consequence-scaled challenge and verification. The final status of each gate in this profile is **CLEARED** or **NOT CLEARED**. Gate One clearance alone does not authorize the machine to act; only an independently cleared Gate Seven Alpha-Lock can release the exact bounded production effect. This is documented as [ordered-clearance errata](https://github.com/alia-june/ethical-and-intellectual-theory/blob/main/blue-prints/gates/ERRATA_2026-11-25_ORDERED_CLEARANCE_ALPHA_LOCK.md).

**Gate Zero is different:** it is an accepted *theoretical foundation*, not one of the seven numbered standing gates. The modular G0-MOD catalog is opt-in per project; theoretical promotion does not imply adoption, implementation, security attestation, or production clearance.

**Status:** Theoretical only. Nothing here is a capability claim about Twin Lanterns, ReShade shader builds, or a deployed AI control system.
