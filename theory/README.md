**Standing gates (one canonical document):** [Production Lock, Reiteration, Hand-off, and Informed Operator Validation](https://github.com/alia-june/ethical-and-intellectual-theory/blob/main/blue-prints/LUNAR_FLOWER_AI_SEED_EXPERT_SYSTEM_CONTRACT.md#standing-expert-system-gates--generic-proposed-contracts). Informed Operator Validation applies whenever explicit human validation is required; generic acknowledgment alone is insufficient, especially for dangerous or sensitive operations. No documentation here activates an operating control.

**Status:** theoretical proposal, not an activated AI control system and not a capability claim about Twin Lanterns or ReShade shader builds.
