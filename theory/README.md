# Lunar Flower — Theory

The **Lunar Flower AI Seed** is a separate, proposed expert-system architecture. It assigns the AI a contract-bound orchestration role, prefers rule-governed and deterministic processes where appropriate, and treats generative decisions as separately reviewed last-resort candidates.

## Distinguishing the gates

The original five standing gates retain their identifiers. **Gate 6 — Prompt Restatement** is a new **proposed** interpretation safeguard: the machine restates the request as it understands it, without turning the restatement into Operator agreement, validation, consent or authorization. Its number is not its execution order; it belongs before substantive work based on that interpretation.

Gate 2 concerns *reiteration of a candidate*, Gate 4 concerns *informed Operator validation*, and Gate 5 concerns optional consequence-scaled challenge and verification. Gate 1's production lock is not overridden by any other gate.

**Gate 0 is different:** it is an accepted *theoretical foundation*, not an active seventh runtime gate. The modular G0-MOD catalog is opt-in per project; theoretical promotion does not imply adoption, implementation, security attestation, or production clearance.

**Status:** Theoretical only. Nothing here is a capability claim about Twin Lanterns, ReShade shader builds, or a deployed AI control system.
